## 1.5.0

### New
- Merge character records: Settings > Character management. Pick a source and a target character
  to move the source's gold quest, Apex Cache, holdings and completion records into the target.
  Use it after a character rename, or when one character shows up twice. The confirmation shows what will be moved.
  Character lists in Character management are sorted by realm, then by name.
- Other Apex Caches (for example the Silvermoon weekly cache) are now recorded when opened on the Earnings tab,
  and the unopened cache alert also shows them.
- Riches tab: the section is now "Apex Caches". Below the Special Assignments, the two Silvermoon weeklies that give
  the Apex Cache (Trailing Xal'atath and Lady Liadrin's weekly) show which characters have done them this week.
  Other caches appear when a character received one this week. Click a line to see each character.
- Jackpots: a cache that gives 3,000 gold or more is a jackpot (silver star), 10,000 gold or more a super jackpot (gold star).
  The new "Cache jackpots" section on the Earnings tab groups them into super jackpots and jackpots; click + to see
  the 10 most recent with date, character and gold,
  and the summary line shows "Cache jackpots 7 (gold star 2, silver star 5)".
- When navigation finishes, a button window offers a way back: Teleport: Silvermoon, Astral Recall,
  hearthstone or the Arcantina key. Each one can be turned off.
- The dashboard and the navigation window now have separate size settings.

### Changes
- Navigation window settings: Settings > Navigation > "Navigation window size" (80% to 150%),
  "Fade the navigation window when the mouse is away" and "Opacity when faded" (10% to 100%).
- New navigation window options: "Small text" (smaller list text and lines, to keep the window large with smaller text)
  and "Background opacity" (only the black background; the text stays as it is).
- Travel steps are named like "Hearthstone: inn (zone)", and the Arcantina key as "Toy: Personal Key to the Arcantina".
  Chat still avoids double colons.
- While navigating, clicking a quest on the Gold Quests tab does not set a waypoint, so the route guidance stays.
- When there is nothing to add to navigation, the navigation window button is "Back to dashboard" instead of "Start".
- After the route is re-planned (for example when a special assignment unlocks), the stop numbers in chat and TomTom
  now match the navigation window instead of starting over from 1.
- Net holdings estimate: shows "Holdings decreasing" (red) or "No change" (gray) instead of "-".
  "-" now only means fewer than two days of records.
- Earnings tab: "Daily average on active days" is shortened to "Daily average".
- Earnings tab: the All view title shows the recorded period ("All (26/10/15 ~ 26/10/29, 15 days)").
- Settings are regrouped: Navigation / Travel in the route / When navigation finishes / Apex Caches.

## 1.5.0 (한국어)

### 새 기능
- 캐릭터 기록 합치기: 설정창 "캐릭터 관리". 원본과 대상 캐릭터를 고르면 원본의 골드퀘, 정점 보관함, 보유량, 완료 기록을 대상에 합칩니다.
  캐릭터 이름을 바꿨거나 같은 캐릭터가 둘로 보일 때 씁니다. 실행 전 확인 창에 옮겨질 기록을 보여 줍니다.
  캐릭터 관리의 캐릭터 목록은 서버별, 이름순으로 정렬합니다.
- 특별 과제 말고 다른 정점 보관함(실버문 주간 최정상 보관함 등)도 열 때 나온 골드를 획득량 탭에 기록하고, 미개봉 알림창에도 띄웁니다.
- 부자되기 탭 묶음 이름을 "정점 보관함"으로 바꾸고, 특별 과제 아래에 최정상 보관함을 주는 실버문 주간 퀘스트 두 줄
  (잘아타스 추적, 리에드린 주간 퀘스트)을 넣었습니다. 줄을 누르면 캐릭터별 이번 주 완료 여부와 미개봉 개수를 보여 줍니다.
  그 밖의 정점 보관함은 이번 주에 받은 캐릭터가 있을 때만 보관함 이름 줄로 보입니다.
- 대박: 보관함 하나에서 3,000골드 이상 나오면 대박(은색 별), 10,000골드 이상이면 초대박(금색 별)으로 표시합니다.
  획득량 탭 "보관함 대박" 묶음에 초대박, 대박으로 나눠 횟수와 골드를 보여 주고, +를 누르면 그 등급의 대박을
  최근 것부터 10개까지 날짜, 캐릭터, 골드와 함께 펼칩니다.
  요약 줄에는 "보관함 대박 7회 (금별2, 은별5)"처럼 보여 줍니다.
- 내비게이션을 마치면 귀환 버튼 창: 실버문 순간이동, 영혼의 귀환, 귀환석, 아르칸티나 열쇠 중 쓸 수 있는 것을 띄웁니다. 수단별로 끌 수 있습니다.
- 대시보드와 내비게이션 창 크기를 따로 설정합니다.

### 변경
- 내비게이션 창 설정 위치: 설정창 "내비게이션" 묶음의 "내비게이션 창 크기"(80% ~ 150%),
  "마우스를 올리지 않았을 때 내비게이션 창을 흐리게", "흐릴 때 불투명도"(10% ~ 100%).
- 내비게이션 창 새 설정: "작은 글씨"(목록 글씨와 줄 간격을 한 단계 작게, 창은 크게 두고 글씨만 줄이고 싶을 때),
  "배경 투명도"(검은 배경만 투명하게, 글씨는 그대로).
- 이동 단계 이름을 "귀환석: 나그네의 쉼터 (실버문)" 꼴로, 아르칸티나 열쇠는 "장난감: 아르칸티나 열쇠"로 바꿨습니다.
  채팅은 쌍점이 겹치지 않게 씁니다.
- 내비게이션 중에는 골드퀘 탭에서 퀘스트를 눌러도 웨이포인트를 찍지 않습니다 (경로 안내가 그대로 유지됩니다).
- 내비게이션에 넣을 곳이 없으면 내비게이션 창 버튼이 "내비게이션 시작!" 대신 "대시보드로 돌아가기"가 됩니다.
- 특별 과제가 열리는 등으로 경로를 다시 짜도 채팅과 TomTom의 목적지 번호가 1부터 다시 시작하지 않고 내비게이션 창 번호와 같습니다.
- 순증 추세 달성 예상: 보유량이 줄고 있으면 빨간 "보유량 감소 중", 변화가 없으면 회색 "변화 없음". "-"는 기록이 2일 미만일 때만.
- 획득량 탭 요약 "수행한 날 하루 평균"을 "하루 평균"으로 줄였습니다.
- 획득량 탭 전체 보기 제목에 기록이 모인 기간을 보여 줍니다 ("전체 (26/10/15 ~ 26/10/29, 15일)").
- 설정창 묶음 정리: 내비게이션 / 동선에 넣는 이동 수단 / 내비게이션을 마칠 때 / 정점 보관함.
