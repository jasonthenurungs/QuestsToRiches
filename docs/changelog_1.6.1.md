## 1.6.1

### New
- Setting "Don't count the Warband Bank in this account's holdings" (Settings > Goal, off by default).
  Game accounts under one license (WoW1, WoW2 and so on) share the Warband Bank, so each account counted the same bank.
  Turn it on in every account but one, and the holdings of your accounts add up without counting the bank twice.
  Goal progress, net holdings change, estimated completion dates and the Holdings tab (past days too) leave the bank out.

### Changes
- Navigation: the Maisara Caverns Mythic+ teleport is now off by default, so its 8-hour cooldown
  (shared with the other Mythic+ teleports) is not used up without you knowing. Turn it on in Settings if you want to use it.
- Holdings tab, detail view: a daily change of 100,000 gold or more is shortened (for example "+204k")
  so it no longer gets cut off in the narrow column.

## 1.6.1 (한국어)

### 새 기능
- 설정 "이 계정 보유량에 전투부대 은행 넣지 않기" (설정창 "목표" 묶음, 기본 끔).
  하위 계정(WoW1, WoW2 등)은 전투부대 은행을 함께 쓰므로 계정마다 같은 은행이 보유량에 들어갔습니다.
  은행을 넣을 계정 하나만 남기고 나머지 계정에서 켜면, 계정별 보유량을 더해도 은행이 두 번 들어가지 않습니다.
  목표 진행률, 보유량 순증, 달성 예상일, 보유량 탭(지난 날짜 포함)에서 은행을 뺍니다.

### 변경
- 내비게이션: 쐐기 포탈(마이사라 동굴 순간이동)을 기본 끔으로 바꿨습니다. 다른 쐐기 순간이동과 함께 도는 8시간 대기시간이
  모르는 사이에 걸리지 않게 했습니다. 쓰려면 설정에서 켜세요.
- 보유량 탭 상세: 캐릭터별 전일비가 10만 골드 이상이면 "+204k"처럼 줄여, 좁은 칸에서 잘리지 않게 했습니다.
