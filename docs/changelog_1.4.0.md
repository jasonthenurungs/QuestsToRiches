## 1.4.0

### New
- Travel abilities in navigation
  - Mage: Teleport: Silvermoon (the Midnight spell) is used like a portal whenever it is faster.
    It has no cooldown, so it can be used several times in one route.
  - Shaman: Astral Recall takes you to your hearthstone inn. Its cooldown is separate,
    so it can be used together with the hearthstone.
  - Personal Key to the Arcantina (toy): enter the Arcantina and take the exit portal to an inn in Silvermoon.
    It has its own 15-minute cooldown. It takes two loading screens, so it is counted as a little slower than the hearthstone.
  - Each one can be turned off in the settings.
- The route is now planned around the hearthstone and the abilities above, not just patched afterwards:
  the order of stops can change so that a hearthstone is used where it saves the most.
  The route is never slower than before, because both ways are compared.
- Humans with two hearthstone charges can use both in one route when "keep one charge" is off.
- Use button: when the next step is a hearthstone, Astral Recall, the Arcantina key or Teleport: Silvermoon,
  a small window appears. Click it to use it. It hides after use and can be moved, closed or turned off.
- Dashboard pin: next to the settings button. When pinned, Esc does not close the dashboard.
- Window size option (80% to 150%) for the dashboard and the navigation window.
  The windows keep their top-left corner and never grow past the screen.

### Changes
- Better route order: groups of stops can be moved to a better place in the route,
  which removes some back-and-forth trips (for example, coming back to the same zone later).
- Route names no longer repeat colons in chat ("Harandar portal (Silvermoon)", "Hearthstone (inn)").
- /qtr hearth also shows the status of travel abilities.

## 1.4.0 (한국어)

### 새 기능
- 내비게이션에 이동 기술
  - 마법사: 실버문 순간이동(한밤 주문)을 포탈처럼 더 빠를 때마다 씁니다.
    대기시간이 없어 한 경로에서 여러 번 쓸 수 있습니다.
  - 주술사: 영혼의 귀환으로 귀환석 여관에 갑니다. 대기시간이 귀환석과 따로라 함께 쓸 수 있습니다.
  - 아르칸티나로 통하는 개인 열쇠 (장난감): 아르칸티나에 들어갔다가 나가는 차원문을 타면 실버문 여관(나그네의 쉼터)으로 나옵니다.
    대기시간 15분이 따로 있고, 로딩이 두 번이라 귀환석보다 조금 느린 것으로 계산합니다.
  - 각각 설정에서 끌 수 있습니다.
- 동선을 귀환석과 위 이동 기술까지 고려해 짭니다. 순서를 먼저 정하고 끼워 넣는 것이 아니라,
  귀환석이 가장 많이 줄여 주는 자리에 오도록 방문 순서 자체를 바꿀 수 있습니다.
  두 방식을 비교해 빠른 쪽을 쓰므로 이전보다 느려지지 않습니다.
- 인간 캐릭터(귀환석 2회 충전)는 "1회 남기기"를 끄면 한 경로에서 두 번까지 씁니다.
- 사용 버튼 창: 다음 단계가 귀환석, 영혼의 귀환, 아르칸티나 열쇠, 실버문 순간이동이면 작은 창이 뜨고,
  누르면 바로 씁니다. 쓰고 나면 사라지고, 옮기거나 닫거나 설정에서 끌 수 있습니다.
- 대시보드 고정 버튼: 설정 버튼 옆 압정. 켜면 Esc를 눌러도 대시보드가 닫히지 않습니다.
- 창 크기 설정 (80% ~ 150%): 대시보드와 내비게이션 창. 창 왼쪽 위 모서리는 제자리에 있고, 화면보다 커지지 않습니다.

### 변경
- 동선 순서 개선: 목적지 몇 곳을 묶어 더 나은 자리로 옮겨 보는 계산을 더해, 같은 지역에 나중에 다시 돌아오는 것 같은 왕복을 줄였습니다.
- 채팅에서 쌍점이 겹치지 않게 경로 이름을 바꿨습니다 ("하란다르행 포탈 (실버문)", "귀환석 (나그네의 쉼터)").
- /qtr hearth에 이동 기술 상태도 함께 표시합니다.
