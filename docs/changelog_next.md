## (next version, number to be decided)

### New
- Navigation: Haranir Rootwalking can be used in the route. It has no cooldown, so it is used like a portal to the Cradle in Harandar
  whenever that is faster. Use it once away from the World Tree roots in Harandar so the addon learns where you land;
  after that it is added to navigation. It is not used near the World Tree roots, because there it takes you to another continent.
  Turn it off under "Use Haranir Rootwalking in navigation" in Settings.

## (다음 버전, 번호는 정해지면) (한국어)

### 새 기능
- 내비게이션: 하라니르 종족 기술 뿌리걸음을 동선에 넣습니다. 쿨타임이 없어서 하란다르의 요람으로 가는 포탈처럼, 더 빠를 때마다 씁니다.
  하란다르의 세계수 뿌리에서 떨어진 곳에서 한 번 쓰면 애드온이 내리는 곳을 기억하고, 그 뒤부터 동선에 들어갑니다.
  세계수 뿌리 근처에서는 다른 대륙으로 가기 때문에 넣지 않습니다.
  설정창 "하라니르 뿌리걸음을 동선에 넣기"에서 끌 수 있습니다.
