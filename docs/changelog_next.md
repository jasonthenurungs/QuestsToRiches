## (next version, number to be decided)

### New
- Navigation: M+ portals now cover every Midnight dungeon teleport you know (Season 1 and Season 2), not only Maisara Caverns.
  They share one cooldown, so one is used per route: the one that saves the most time. Each dungeon can be turned off in Settings,
  and landing spots that are estimated are learned the first time you use each teleport. Still off by default
  ("M+ portals (dungeon teleports)" in Settings).

### Changes
- Settings: travel method options are named shorter ("Hearthstone" instead of "Use the Hearthstone in navigation"),
  since they are already under "Travel methods used in navigation".

### Fixes
- Riches tab: the Liadrin weekly now includes the world quest version, so characters who did it show as done.
- Riches tab: the Liadrin weekly runs on a two-week cycle shared by all characters. In the first week of a new cycle,
  characters who did it the week before are no longer shown as "Done last week".
- Navigation: the use window now appears again when Haranir Rootwalking (or Mage Teleport: Silvermoon) is used twice in one route.

## (다음 버전, 번호는 정해지면) (한국어)

### 새 기능
- 내비게이션: 쐐기 포탈이 마이사라 동굴만이 아니라 배운 한밤 던전 순간이동 모두를 봅니다 (시즌 1, 시즌 2).
  쿨타임을 함께 쓰므로 한 동선에서 가장 많이 빨라지는 곳 하나만 씁니다. 설정창에서 던전별로 끌 수 있고,
  내리는 곳을 어림으로 잡은 던전은 처음 쓸 때 실제로 내린 곳을 기억합니다. 지금처럼 기본 끔입니다
  (설정창 "쐐기 포탈 (던전 순간이동)").

### 바뀐 점
- 설정창: "동선에 넣는 이동 수단" 묶음 안의 항목 이름에서 반복되던 "~을 동선에 넣기"를 뺐습니다 ("귀환석을 동선에 넣기" -> "귀환석").

### 수정
- 부자되기 탭: 리에드린 주간 중 전역 퀘스트 종류를 해도 완료로 나오지 않던 문제를 고쳤습니다.
- 부자되기 탭: 리에드린 주간은 모든 캐릭터가 같은 2주 주기로 돕니다. 새 주기 첫째 주에는 지난주에 한 캐릭터를 "지난주 완료"로 표시하지 않습니다.
- 내비게이션: 한 동선에서 뿌리걸음(또는 마법사 실버문 순간이동)을 두 번째 쓸 차례에 사용 창이 뜨지 않던 문제를 고쳤습니다.
