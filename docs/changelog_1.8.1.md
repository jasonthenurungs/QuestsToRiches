## 1.8.1

### New
- Navigation: M+ portals now cover every Midnight dungeon teleport you know (Season 1 and 2), not only Maisara Caverns.
  One is used per route (they share a cooldown). Each dungeon can be turned off in Settings. Still off by default.

### Changes
- Haranir Rootwalking is now on by default and no longer experimental. Dundun's toy is no longer experimental (still off by default).
- Settings: shorter travel method names ("Hearthstone" instead of "Use the Hearthstone in navigation").

### Fixes
- Riches tab: the Liadrin weekly now counts the world quest version, and no longer shows "Done last week" when a new two-week cycle starts.
- Navigation: the use window now appears when Rootwalking or Mage Teleport is used a second time in one route.

## 1.8.1 (한국어)

### 새 기능
- 내비게이션: 쐐기 포탈이 마이사라 동굴만이 아니라 배운 한밤 던전 순간이동을 모두 봅니다 (시즌 1, 2).
  쿨타임을 함께 써서 한 동선에 한 번만 씁니다. 설정창에서 던전별로 끌 수 있습니다. 기본 끔은 그대로입니다.

### 바뀐 점
- 하라니르 뿌리걸음이 기본 켬이 되었고 시험 기능 표시를 뗐습니다. 둔둔 장난감도 시험 기능 표시를 뗐습니다 (기본 끔 그대로).
- 설정창: 이동 수단 항목 이름을 짧게 했습니다 ("귀환석을 동선에 넣기" -> "귀환석").

### 수정
- 부자되기 탭: 리에드린 주간의 전역 퀘스트 종류도 완료로 세고, 새 2주 주기가 시작되면 "지난주 완료"로 표시하지 않습니다.
- 내비게이션: 한 동선에서 뿌리걸음이나 마법사 순간이동을 두 번째 쓸 때 사용 창이 뜨지 않던 문제를 고쳤습니다.
